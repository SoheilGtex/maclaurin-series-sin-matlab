# Results

**RESULTS PENDING MATLAB EXECUTION** in the current sandbox. The directory structure separates evidence by purpose:

- `raw/`: machine- and release-specific CSV outputs generated by the experiment driver.
- `reference/`: selected outputs that may be committed only after genuine MATLAB execution and review.
- `figures/`: generated PNG figures suitable for public presentation after review.

Run from the repository root in MATLAB:

```matlab
addpath('src');
addpath('experiments');
generateAllFigures;
```

No numerical result is pre-populated by hand. CI uploads generated artifacts but does not automatically commit them.
